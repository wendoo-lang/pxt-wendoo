# Wendoo for MakeCode Arcade

Give your sprites brains.

[Wendoo](https://wendoo.com) lets you program a sprite with **rules**. Every
rule has two sides: **WHEN** something happens, **DO** something about it. A
brain is a small set of rules, and it reads like sentences:

- WHEN [see] [player] DO [move toward]
- WHEN [bump] [wall] DO [turn around]

You draw a character in Arcade's image editor, give it a brain, and spawn it
into your game. The brain runs on its own -- every copy of that sprite thinks
for itself.

> **Heads up:** this extension is under development. It is not ready to use in
> your games yet. This page will grow real instructions as pieces come alive.

## Add this extension

1. Open [Microsoft MakeCode Arcade](https://arcade.makecode.com/) and open
   your project.
2. Click the gearwheel menu, then **Extensions**.
3. Paste this into the search box and press Enter:

   https://github.com/wendoo-lang/wendoo-arcade/makecode/extensions/core

4. Click the **wendoo-core** card to add it.
