# Wendoo for MakeCode Arcade

Give your sprites programs made in [Wendoo](https://wendoo.com).

A Wendoo program is a set of rules -- **WHEN** something happens, **DO**
something about it. This extension runs the programs in your project on
your sprites: place **run program ... on mySprite**, pick a program by
name, and the sprite runs it from the next frame until it is destroyed.

> **Heads up:** this extension is under development and not ready to use in
> your projects yet.

To add it to a project:

1. Open your MakeCode Arcade project.
2. Click the gearwheel menu, then **Extensions**.
3. Paste this into the search box and press Enter:

   https://github.com/wendoo-lang/pxt-wendoo/makecode/extensions/arcade

---

Developers: the source lives in the
[pxt-wendoo](https://github.com/wendoo-lang/pxt-wendoo) repository. This
extension builds on the Wendoo VM extension, which it pulls in; see the
repository README for how the project fits together.
